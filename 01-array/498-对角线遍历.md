# 498. 对角线遍历

> **难度**：中等
> **标签**：数组 · 矩阵 · 模拟
> **原题链接**：https://leetcode.cn/problems/diagonal-traverse/

---

## 一、题目描述

给一个 `m × n` 的矩阵 `mat`，按「对角线之字形」的顺序把所有元素装进一个一维数组返回：第一条对角线（只含左上角）向上，第二条向下，第三条向上……方向逐条交替，每条都走完整条对角线再换下一条。

### 示例

```text
输入：mat = [[1,2,3],
            [4,5,6],
            [7,8,9]]
输出：[1,2,4,7,5,3,6,8,9]
解释：k=0 向上 [1] → k=1 向下 [2,4] → k=2 向上 [7,5,3] → k=3 向下 [6,8] → k=4 向上 [9]
```

### 约束条件

- `m == mat.length`，`n == mat[i].length`
- `1 <= m, n <= 10^4`
- `1 <= m * n <= 10^4`
- `-10^5 <= mat[i][j] <= 10^5`

---

## 二、解题思路

### 核心思想

**同一条对角线上的元素满足 `i + j = k` 为常数。** 于是「二维平面上的之字形走位」可以拆成 `m + n - 1` 条互相独立的一维对角线：每条只需知道列下标 `j` 的闭区间，再按 `k` 的奇偶决定要不要翻转。

### 思路演进

1. **暴力解法（走格子模拟）**：从 `(0,0)` 出发，带着方向 `(+1,-1)`（左下）或 `(-1,+1)`（右上）一格一格走。越界时按规则修正：撞上边界则先回到合法格子、再换方向、再前进一步。最麻烦的是四个角各有各的接续方式（右上角要下移一格且方向不变，左下角要右移一格且方向不变，其余情况是撞哪边就补哪边 + 换方向）。时间 O(mn)、额外空间 O(1)，但四个角的分支最容易漏，写完还要手推一遍边界。
2. **观察到**：模拟之所以要那么多分支，是因为它把「访问顺序」和「越界修正」耦合在了同一个循环里。但访问顺序其实有独立的、纯算术的描述 —— 第 `k` 条对角线的全部元素就是 `i + j == k` 的那些格子，与上一条对角线毫无关系。方向交替也不是"走出来的"，只是 `k` 的奇偶。
3. **优化为（按层直接取）**：外层枚举 `k = 0 … m+n-2`，内层只枚举列下标 `j`。固定 `k` 时，格子 `(k-j, j)` 合法当且仅当 `0 <= j <= n-1` 且 `0 <= k-j <= m-1`，反解得

   ```text
   j ∈ [ max(0, k-(m-1)),  min(n-1, k) ]
   ```

   在这个区间里让 `j` 从**小到大**取 `mat[k-j][j]`，得到的是「从这条对角线的下端一路上右上行」。偶数 `k` 正好要的就是这个方向，直接拼接；奇数 `k` 要反向，切片后 `reverse()`。一次区间计算 + 一次列表推导就够了，全程没有一个边界判断分支。

### 关键点

- **循环变量取列下标 `j`，不要取行下标。** `mat[k-j][j]` 里行是 `k-j`、列是 `j`，区间公式也必须按 `j` 写：左端 `max(0, k-m+1)`（行不能超过 `m-1` 压下来的）、右端 `min(n-1, k)`（列不能超过 `n-1` 压下来的）。把左端写成 `k-n+1` 是这类题最隐蔽的错误 —— **在方阵上恰好也对**，非方阵才炸。
- **方向约定**：`j` 递增 ⇒ 列增、行减 ⇒ 天然是「右上」。偶数 `k` 要右上（不翻），奇数 `k` 要左下（翻）。
- **`k` 的上界是 `m+n-2`**，所以循环写 `range(m + n - 1)`。
- 单行 / 单列 / 1×1 都落在同一套公式里，无需特判。

## 三、代码实现

### 最终代码

```python
class Solution:
    def findDiagonalOrder(self, mat: list[list[int]]) -> list[int]:
        m = len(mat)
        n = len(mat[0])
        ans = []
        for k in range(m + n - 1):
            min_j = max(0, k - m + 1)      # 保证 k - j <= m - 1
            max_j = min(n - 1, k)          # 保证 j <= n - 1
            a = [mat[k - j][j] for j in range(min_j, max_j + 1)]
            if k % 2 == 1:                 # 奇数条要反向（左下）
                a.reverse()
            ans.extend(a)
        return ans
```

## 四、复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| :--- | :--- | :--- |
| **最终代码** | O(mn) | O(min(m,n)) 临时 + O(mn) 返回值 |
| 走格子模拟 | O(mn) | O(1) 额外 + O(mn) 返回值 |
| 理论下界 | O(mn) | O(mn)（返回值本身） |

> 复杂度中的 n 指矩阵元素总数 `m·n`；`m`、`n` 分别为行数与列数。每个元素恰被写入输出一次，所以 O(mn) 不可再降。

## 五、优化评估

**结论**：时间已是理论下界，**额外空间还有一档可优化**（去掉每条对角线的临时列表）。

### 瓶颈分析

时间上必须把 `mn` 个元素各自搬进输出一次，O(mn) 是硬下界，没有讨论余地。真正的差别只在常数：当前实现在偶数 `k` 上靠切片一次性取出整条对角线（C 层批量搬运），在奇数 `k` 上再整体 `reverse`；总数上大约一半的对角线要翻转。

空间上，`a` 的长度最多是 `min(m,n)`（最长那条对角线），随 `k` 变化反复创建。

### 可优化空间

把「先建列表再翻」换成「按需要的方向直接遍历下标写进 `ans`」，临时列表就消失了，额外空间降到 O(1)：

### 优化代码

```python
class Solution:
    def findDiagonalOrder(self, mat: list[list[int]]) -> list[int]:
        m, n = len(mat), len(mat[0])
        ans = []
        for k in range(m + n - 1):
            lo = max(0, k - m + 1)
            hi = min(n - 1, k)
            rng = range(lo, hi + 1) if k % 2 == 0 else range(hi, lo - 1, -1)
            for j in rng:
                ans.append(mat[k - j][j])
        return ans
```

**优化理由**：`range` 支持负步长，所以「反向」这一步不必真的把列表倒过来 —— 直接把 `j` 的遍历方向反过来即可，既省掉临时列表，也省掉 `reverse`。代价是搬运从列表推导的批量操作退化成逐元素 `append`，两者大 O 相通，本题规模 `m·n ≤ 10^4` 下都远在时限内。**追求空间就选后者，追求写法紧凑就保留原版**，没有绝对优劣。

### 常数级优化（可选）

- 用 `ans.extend(a)` 而不是 `for x in a: ans.append(x)`，批量扩展少一层解释器开销。
- `a.reverse()` 是原地操作、返回 `None`，别写成 `a = a.reverse()`（那样会得到 `None`，下一行 `extend` 直接报错）。

## 六、易错点与总结

### 易错点

- **翻错奇偶**：`j` 递增的天然方向是「右上」，偶数 `k` 要右上 ⇒ 不翻、奇数 `k` 翻。写反时首个对角线（单元素）看不出问题，要到 `k=1` 才暴露 —— 3×3 会把 `[2,4]` 输出成 `[4,2]`。
- **区间左端混淆行列**：循环变量是 `j`，左端必须是 `max(0, k-m+1)`。误写成 `max(0, k-n+1)`（那是行下标的区间）在**方阵上完全正确**，一碰非方阵就越界或漏元素，`2×3` 矩阵是标准试金石。
- **行列写反**：`mat[k-j][j]` 是「列增行减」的对角线；写成 `mat[j][k-j]` 变成按行递增取，整个输出顺序都不对。
- **`range` 上界漏 `+1`**：`range(min_j, max_j)` 会丢掉每条对角线的最后一个格子。
- **`k` 的个数写成 `m+n`**：多跑一轮空循环，`lo > hi`，切片为 `[]`，不会报错但逻辑上多余；正确是 `m+n-1`。

### 题型套路沉淀

- **常数和分层**：矩阵题先问「能不能用 `i+j`（或 `i-j`）当层号」。主对角线族、反对角线族、托普利茨判定、对角线排序/求和，全是「按层号聚合 + 层内按需排序/翻转」这一个模子。
- **层内区间的通用求法**：把两个约束 `0 <= j <= n-1`、`0 <= k-j <= m-1` 解成 `j` 的闭区间，比逐个判越界更不容易错，也天然处理了非方阵。
- **方向交替的写法**：不要写两套循环，而是「统一按一个方向取，再对另一半翻转」（或用 `range` 的负步长）。奇偶判定只此一处，改起来不会漏。
- 写完先用 `1×n`、`n×1`、`2×3` 三个非方阵手推 —— 方阵过得了不代表对。
