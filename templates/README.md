# templates/

本目录存放笔记的**书写规范参考**，不参与题目分类，也不会被 `scripts/update_index.py` 统计。

| 文件 | 说明 |
| :--- | :--- |
| [`note-template.md`](note-template.md) | **空白模板**。新建笔记时复制它，把 `{{占位符}}` 替换为实际内容。 |
| [`example-note.md`](example-note.md) | **完整示例**（以 LeetCode 1. 两数之和为例）。展示一份合格笔记应有的深度与结构，可作为质量基准。 |

## 关于 example-note.md

它只是**格式范例**，不代表仓库作者已归档该题。正式笔记请放在对应的题型目录下，例如：

```text
03-hash-table/1-两数之和.md
```

## 笔记六要素

一份笔记必须包含：

1. **题目信息** — 题号、题名、难度、标签、LeetCode 链接
2. **题目描述** — 题意复述、示例、约束条件
3. **解题思路** — 核心思想、思路演进、关键点
4. **代码实现** — 最终通过的代码
5. **复杂度分析** — 时间 / 空间复杂度，并与理论下界对比
6. **优化评估** — 瓶颈在哪、能否更优；**可优化则必须附优化代码与理由**
