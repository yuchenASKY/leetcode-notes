# 1524. 和为奇数的子数组数目

> **难度**：中等
> **标签**：数组 · 数学 · 动态规划 · 前缀和
> **原题链接**：https://leetcode.cn/problems/number-of-sub-arrays-with-odd-sum/

---

## 一、题目描述

给定一个正整数数组 `arr`，统计其中**元素之和为奇数**的连续子数组的个数。由于答案可能很大，返回对 `10^9 + 7` 取余后的结果。

### 示例

```text
示例 1：
输入：arr = [1,3,5]
输出：4
解释：全部 6 个子数组的和依次为 1, 4, 9, 3, 8, 5，其中奇数有 1, 9, 3, 5，故答案为 4。

示例 2：
输入：arr = [2,4,6]
输出：0
解释：全部元素都是偶数，任何子数组的和都是偶数。

示例 3：
输入：arr = [1,2,3,4,5,6,7]
输出：16
```

### 约束条件

- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 100`
- 结果对 `10^9 + 7` 取余

---

## 二、解题思路

### 核心思想

**子数组和的奇偶性只由「两个前缀和的奇偶性是否不同」决定** —— 于是问题从「枚举子数组」降维成「数前缀奇偶性的配对」。

### 思路演进

1. **暴力解法**：枚举所有 `(i, j)` 共 `n(n+1)/2` 个子数组，用前缀和 O(1) 求每个的和再判奇偶。时间 O(n²)。n = 10^5 时约 5×10^9 次操作，必然超时。
2. **观察到**：判奇偶根本不需要知道和的具体数值，只需要它「是不是奇数」。而 `sum(i..j)` 的奇偶性 = `pref[j] ^ pref[i-1]` 的奇偶性（和的奇偶性等于奇偶性的异或 / 相加再取奇偶）。也就是说：**`pref[j]` 与 `pref[i-1]` 一个奇一个偶 ⟺ 子数组和为奇**。
3. **关键转化**：把「数子数组」换成「数前缀对的组合」——所有前缀和（含下标 `-1` 处的空前缀 `0`）按奇偶分成两组，每次取「一组中的前缀」与「另一组中已经出现过的前缀」组成一对，恰好对应一个和为奇的子数组。
4. **优化为**：顺序扫描前缀，维护两个计数器 `even` / `odd`（已出现过的偶 / 奇前缀个数，空前缀 `0` 计入偶，初始 `even = 1`）。遇到奇前缀就累加 `even`，遇到偶前缀就累加 `odd`，然后把当前前缀计入对应计数器。一趟 O(n) 扫完。

同一件事换个角度看，就是**动态规划**：令 `dp[i]` = 以 `i` 结尾、和为奇数的子数组个数。以 `i` 结尾的子数组共 `i+1` 个，若 `arr[i]` 为奇，则「和为偶」的那些（共 `i - dp[i-1]` 个，`i ≥ 1`）在前接上 `arr[i]` 后全部变成奇，故 `dp[i] = (i + 1) - dp[i-1]`；若 `arr[i]` 为偶，接上偶数不改变奇偶性，`dp[i] = dp[i-1]`。答案 = `Σ dp[i]`。两条路线本质等价，下面的代码走的是「前缀奇偶计数」这一条，因为它不需要单独处理下标 0 的边界。

### 关键点

- **空前缀必须计入**：下标 `-1` 处的 `pref = 0`（偶）代表「从数组开头开始的子数组」，漏掉它会丢掉所有以 `arr[0]` 起头的答案。
- **配对要「先数后记」**：先用当前前缀去和**已经出现过**的前缀配对，再把自己加进计数器 —— 顺序反了会把自己和自己配成一对（对应长度 0 的子数组，不合法）。
- **只需奇偶，不需真值**：`% 2` 或 `& 1` 就够了，前缀和的具体大小对答案毫无影响。
- **取余放在最后**：中间累加用 Python 大整数不会溢出；若要边加边取模也可以，`ans % MOD` 与「逐步取模」结果一致（加法对取模封闭）。

## 三、代码实现

### 最终代码

```python
from typing import List
from itertools import accumulate
from collections import defaultdict


class Solution:
    def numOfSubarrays(self, arr: List[int]) -> int:
        MOD = 10 ** 9 + 7
        pref = list(accumulate(arr))     # pref[i] = arr[0] + ... + arr[i]
        cnt = defaultdict(int)           # cnt[p] = 已出现过的「前缀和奇偶性为 p」的个数
        cnt[0] = 1                       # 空前缀（下标 -1）的和为 0，是偶数
        ans = 0
        for s in pref:
            p = s % 2
            if p == 1:                   # 当前前缀为奇 → 需要前面出现过偶前缀
                ans += cnt[0]
            else:                        # 当前前缀为偶 → 需要前面出现过奇前缀
                ans += cnt[1]
            cnt[p] += 1                  # 统计完再把自己计入，避免自配
        return ans % MOD
```

> 截图里的代码只有 `class Solution` 本体，三行 `import` 是截图里没有、事后补齐的（`List` / `accumulate` / `defaultdict`）。

| :--- | :--- | :--- |
| **最终代码** | O(n) | O(n) |

## 五、优化评估

**结论**：时间复杂度已达理论下界，**空间还有一档可压（O(n) → O(1)）**。

### 瓶颈分析

每个元素至少要看一次才能知道它的奇偶性，因此 O(n) 时间不可突破；当前的 O(n) 空间纯粹是为了保存整条前缀和数组和各奇偶前缀的计数，属于「可省」的那部分。

### 可优化空间

前缀和的奇偶性只需**边扫边滚**：维护一个 `pref` 累加变量和两个整数计数器 `even` / `odd`，不必把整条前缀和数组存下来，空间降到 O(1)。这不仅省内存，也省掉了一次 `accumulate` 的中间列表。

### 优化代码

```python
from typing import List


class Solution:
    def numOfSubarrays(self, arr: List[int]) -> int:
        MOD = 10 ** 9 + 7
        even, odd = 1, 0      # 偶 / 奇前缀的个数；空前缀的 0 算一个偶前缀
        pref = ans = 0
        for x in arr:
            pref += x
            if pref & 1:      # 当前前缀为奇 → 与之前每个偶前缀配对
                ans += even
                odd += 1
            else:             # 当前前缀为偶 → 与之前每个奇前缀配对
                ans += odd
                even += 1
        return ans % MOD
```

**优化理由**：奇偶配对只用「此前出现过多少个偶前缀 / 奇前缀」，与它们的**位置和具体取值都无关** ⇒ 两个计数器就够了，无需保留前缀和序列本身。

### 常数级优化（可选）

- 判奇偶用 `pref & 1` 比 `pref % 2` 少一次取模语义，且对负数同样成立。
- 若数组很长且担心 `ans` 膨胀，可在累加后立即 `ans %= MOD`；本题 `ans` 上界约为 `n²/2 ≈ 5×10^9`，Python 整数完全放得下，放在结尾一次性取模即可。

## 六、易错点与总结

### 易错点

- **忘掉空前缀**：`cnt[0] = 1` / `even = 1` 漏写，会恰好丢掉所有「从 `arr[0]` 开始且和为奇」的子数组，答案偏小。
- **先记后数**：`cnt[p] += 1` 写在配对之前，当前前缀会和自己配对，产生非法贡献。
- **配对方向搞反**：当前前缀为奇时要去配**偶**前缀（奇 − 偶 = 奇），写成配奇前缀就全错了。
- **`defaultdict` 的隐式插入**：用 `cnt[0]` / `cnt[1]` 直接读是安全的（这里两个键都已存在），但如果改成按值域开桶，读操作本身会建键，注意别让「查询」变成「写入」。
- **只判总和**：把「子数组和是奇数」误读成「子数组里有奇数元素」—— 例如 `[1,1]` 的和是偶，虽然有奇数元素。

### 题型套路沉淀

- **「子数组和的奇偶 / 整除性」→ 前缀和的奇偶 / 余数配对**：只要问的是「有多少个子数组满足某整除 / 奇偶性质」，标准动作就是「前缀余数 + 计数桶」，把 O(n²) 的枚举降成 O(n) 的一次扫描。同型：`974. 和可被 K 整除的子数组`、`560. 和为 K 的子数组`、`1590. 使数组和能被 P 整除`。
- **计数型 DP 的等价改写**：`dp[i]` 只依赖 `dp[i-1]` 与下标，滚动一个变量即可；而它和「前缀奇偶计数」是同一枚硬币的两面 —— 看到其中一种，能立刻写出另一种。
- **只关心奇偶时不要算真值**：`% 2` / `& 1` 就够，避免无谓的大数运算与大整数累加。
