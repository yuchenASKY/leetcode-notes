## 一、题目描述

给定一个非负整数 `s`，对每个候选边长 `n` 构造三维数组 `A`（维度 `n × n × n`），其中

```text
A[i][j][k] = i * (j OR k)，  0 <= i, j, k < n
```

求使得 **A 中所有元素之和不超过 `s`** 的 **最大** `n`。

注意 `i` 是乘数（不是被 OR 的一项），所以 `A[0][*][*]` 整层都是 0。

### 示例

```text
输入：s = 10
输出：2
解释：n = 2 时共有 8 个元素，其中 A[0][*][*] 四个全为 0，
      A[1][0][0] = 1 * (0 OR 0) = 0，A[1][0][1] = 1 * (0 OR 1) = 1，
      A[1][1][0] = 1 * (1 OR 0) = 1，A[1][1][1] = 1 * (1 OR 1) = 1，
      总和为 3 <= 10；而 n = 3 时总和为 45 > 10，故答案为 2。

输入：s = 0
输出：1
解释：n = 1 时数组只有一个元素 A[0][0][0] = 0 * (0 OR 0) = 0，总和为 0 <= 0。
```

### 约束条件

- `0 <= s <= 10^15`

---

## 二、解题思路

### 核心思想

**先把三重求和拆成「1 到 n-1 的等差和」×「所有 (j|k) 之和」，再按二进制位统计 `j|k` 每一位被算到的次数；总和对 n 单调，于是二分答案。**

### 思路演进

1. **暴力解法**：给定 `n`，直接三重循环累加 `i * (j|k)`，单次求值是 O(n³)；再从小到大枚举 `n` 找最后一个不超过 `s` 的，整体 O(n⁴)。而由约束可以粗估量级：`Σ_{j,k}(j|k)` 是 n² 个数对的和、每个数对平均是 Θ(n) 量级，故它是 Θ(n³)；再乘上 `Σ_i i = Θ(n²)`，元素总和是 Θ(n⁵)。要让 `Θ(n⁵) <= 10^15`，`n` 只能是 10³ 量级（实际答案不超过约 1.3 × 10³）。`n³` 已是 10⁹，单次判定就顶不住，必须换算法。

2. **观察到（分离变量）**：三重求和里 `i` 只作为乘数出现，与 `(j|k)` 毫无耦合 —— 变量可以直接分开：

   ```text
   Σ_{i,j,k} i * (j|k) = (Σ_{i<n} i) · (Σ_{j,k<n} (j|k)) = [n(n-1)/2] · S_or
   ```

   于是三维问题降成二维。但 `S_or` 若靠枚举数对求，仍是 O(n²)，而二分要对 O(log N) 个候选 `n` 各求一次，乘起来还是太慢。

3. **关键转化（按位拆贡献）**：OR 的每一位彼此独立，`(j|k)` 这个整体值不好求，但它每一位的贡献可以分开数：

   ```text
   S_or = Σ_b 2^b · cnt_b,   cnt_b = #{ (j,k) : 第 b 位在 j|k 中为 1 }
   ```

   而「至少有一个为 1」不好直接数，转成补集 —— 数对总数减去「两个数该位都是 0」的数对：

   ```text
   cnt_b = n² - zeros_b²,   zeros_b = [0, n-1] 中第 b 位为 0 的整数个数
   ```

   剩下的只有 `zeros_b`（等价于 `ones_b = n - zeros_b`）：第 b 位在自然数序列上以 `2^(b+1)` 为周期循环，每个完整周期里恰好有 `2^b` 个数的该位为 1 —— 于是区间计数能用闭式算出，O(1) 搞定一位。

4. **二分答案**：`f(n)` = 边长为 n 时元素总和，随 n **严格单调递增**（n 变大只会多出一批非负的新元素），满足「最大可行整数 + 可行性单调」的二分答案结构。上界取一个足够大的数（代码里 `1e16`，远大于实际答案量级），每轮判定只扫 60 个二进制位。

### 关键点

- **变量解耦**：`i` 是乘数、与 `(j|k)` 独立，这是把三维降到二维的第一步，也是最容易被「三重循环」思维挡住的一步。
- **按位独立 + 补集计数**：本题的核心转化。「至少一个为 1」→ 总数 − 「两个都为 0」；写成式子就是 `n² - zeros_b²`，把难数的量换成好数的量。
- **区间位计数的周期公式**要处理余数段：`[0, upper]` 中第 b 位为 1 的个数 = `⌊upper / 2^(b+1)⌋ · 2^b + max(0, upper mod 2^(b+1) - 2^b + 1)`。后半段里只有落在 `[2^b, 2^(b+1) - 1]` 的部分该位才是 1，别漏掉末尾那一项。
- **边界与开闭**：`s = 0` 时答案是 1（`n = 1` 的唯一元素是 0，总和为 0），所以二分左界取 **1** 而不是 0；判定用 `<=`（题目是「不超过」），写成 `<` 会在总和恰好等于 `s` 时丢掉答案。
- **高位必须返回 0**：候选 `n` 小的时候，高于 `n-1` 位长的那些位不该产生任何贡献，代码用 `k >= upper.bit_length()` 直接短路，避免余数段算出无意义的正数。
- **上界要给够**：`f(n)` 是 Θ(n⁵) 级别的增长速度，但它在 n 很小的时候（前几十）可能仍远小于 `s`；上界若取得比真实答案小，二分会返回一个偏小的错值。

## 三、代码实现

```python
def calc(upper: int, k: int) -> int:
    """返回 [0, upper] 中第 k 位为 1 的整数个数（upper >= 0）。"""
    if k >= upper.bit_length():      # upper < 2^k，这一位谁都没带
        return 0
    # 完整周期：每 2^(k+1) 个数里有 2^k 个数的第 k 位为 1
    res = upper // (1 << (k + 1)) * (1 << k)
    upper %= 1 << (k + 1)
    if upper >= 1 << k:              # 余数落在周期的后半段
        res += upper - (1 << k) + 1
    return res


class Solution:
    def maxSizedArray(self, s: int) -> int:
        def check(mid: int) -> bool:
            # 边长 mid：总和 = [mid*(mid-1)/2] * Σ_{j,k<mid}(j|k)
            pairs = mid * mid                       # 数对总数
            sum0r = 0                               # Σ_{j,k}(j|k)（按位累加）
            for b in range(60):
                ones = calc(mid - 1, b)             # [0, mid-1] 中第 b 位为 1 的个数
                zeros = mid - ones                  # [0, mid-1] 中第 b 位为 0 的个数
                any0nes = pairs - zeros * zeros     # (j|k) 第 b 位为 1 的数对个数（补集）
                sum0r += any0nes * (1 << b)
            sum1 = mid * (mid - 1) // 2             # Σ_i i
            return sum1 * sum0r <= s

        left = 1
        right = int(1e16)
        while left <= right:
            mid = (left + right) // 2
            if check(mid):              # mid 可行，试更大的
                left = mid + 1
            else:
                right = mid - 1
        return right                    # 最后一个可行的 mid
```

## 四、复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| :--- | :--- | :--- |
| **最终代码** | O(B · log N) | O(1) |
| 朴素解法（枚举 n + 三重循环求和） | O(n⁴) | O(1) |
| 理论下界 | O(log N · log n) | O(1) |

> 复杂度中的 n 指：最终要求的数组边长（答案，量级 10³）；N 指二分上界（代码取 `10^16`）；B 指参与统计的二进制位数（代码固定取 60，因为 `10^16 < 2^54`，够用且是常数）。
>
> 最终代码每轮判定扫 B = 60 个位、每个位 O(1) 算术，共 log N 轮二分；朴素解法对每个候选 n 花 O(n³) 累加、逐个枚举候选共 O(n⁴)，在 n 为 10³ 量级时完全不可行。单个候选的判定从 O(n³) 降到 O(B)，是本题的全部收益来源。
