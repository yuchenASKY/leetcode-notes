# 3807. 修复边以遍历图的最小成本

> **难度**：中等
> **标签**：二分查找 · 图 · BFS
> **原题链接**：https://leetcode.cn/problems/minimum-cost-to-repair-edges-to-traverse-a-graph/（Plus 会员题）

## 一、题目描述

给定一个含 n 个节点（编号 `0 ~ n-1`）的无向图，用二维数组 `edges` 表示，其中 `edges[i] = [u, v, w]` 表示节点 `u` 与 `v` 之间有一条**修复成本为 w** 的边。所有边一开始都是**损坏**状态，不可使用。

你可以选定一个非负整数 `money`，一次性把所有满足 `w <= money` 的边修好，其余边保持损坏、无法使用。要求从节点 0 出发，**使用不超过 k 条边**到达节点 `n-1`。返回实现该目标所需的**最小 money**；若无论 money 取多大都做不到，返回 `-1`。

一句话概括：找到最小的预算阈值，使得「只保留成本不超过该阈值的边」后，0 到 n-1 之间存在一条**边数 ≤ k** 的路径。

### 示例

```text
示例 1
输入：n = 3, edges = [[0,1,10],[1,2,10],[0,2,100]], k = 1
输出：100
解释：k = 1 意味着必须一步从 0 走到 2，唯一可行的是 0 -> 2 这条边，
      它的修复成本为 100，因此 money 至少为 100。

示例 2
输入：n = 6, edges = [[0,2,5],[2,3,6],[3,4,7],[4,5,5],[0,1,10],[1,5,12],[0,3,9],[1,2,8],[2,4,11]], k = 2
输出：12
解释：money = 12 时所有 w <= 12 的边都可用，路径 0 -> 1 -> 5 恰好用 2 条边；
      money < 12 时不存在长度不超过 2 的 0 -> 5 路径。

示例 3
输入：n = 3, edges = [[0,1,1]], k = 1
输出：-1
解释：节点 2 是孤立点，任何 money 都无法到达。
```

### 约束条件

- `2 <= n <= 5 * 10^4`
- `1 <= edges.length == m <= 10^5`
- `edges[i] = [u_i, v_i, w_i]`，其中 `0 <= u_i, v_i < n`
- `1 <= w_i <= 10^9` —— 边权上界很大，直接枚举 money 不可行
- `1 <= k <= n`
- 图中无自环、无重边

## 二、解题思路

### 核心思想

**答案单调 ⇒ 二分答案。** 谓词 `check(money)` 定义为「预算为 money 时，能否用不超过 k 条边从 0 走到 n-1」，它对 money 单调（False…False True…True）。而区间内的可行性判定本身是一个**无权图最短路（边数最少）**问题，用 BFS 分层求解。

### 思路演进

1. **暴力解法**：money 是个整数，最直白的做法是让 money 从 0 开始逐个递增，每次把 `w <= money` 的边加进图、跑一次 BFS 看能否在 k 步内到达终点。问题在于 `w_i <= 10^9`，money 的取值空间大到无法枚举。
2. **第一次收敛**：注意到 money 只在**跨过某条边的成本**时才改变可用边集合 —— 在两个相邻边权之间取任何值，可用边完全相同。因此最优解一定是某条边的 `w`，候选值只有 m 个（≤ 10^5）。但逐个候选做 BFS 仍是 `10^5 × (5×10^4 + 10^5) ≈ 10^10` 量级，必然超时。
3. **第二次收敛（关键）**：候选值之间并非无序 —— **money 越大，被修好的边只增不减，可用子图只会更"连通"，从 0 到 n-1 的最少边数只会更小或不变**。即 `check(money)` 在候选序列上形如 `False, False, …, True, True`。看到这种「一段失败 + 一段成功」的结构，就应该**二分答案**，把判定次数从 O(m) 降到 O(log)。
4. **优化为**：既不枚举候选边权、也不排序，直接在数值区间 `[0, max_w]` 上二分。每次 `check(money)` 做一次 BFS：把满足 `w <= money` 的边视为长度 1 的边，从节点 0 开始逐层扩展；因为可用边之间没有任何权重差别，**第一次松弛到 n-1 时的层数就是最少边数**，直接与 k 比较即可。
5. **收尾**：若连 `money = max_w`（所有边全部修好）都无法在 k 步内到达，说明终点不可达，返回 -1。

### 关键点

- **单调性是二分的许可证**：`money ↑` ⇒ 可用边集合单调增 ⇒ 最少边数单调不增 ⇒ 谓词单调。写题时要把这条链在脑子里过一遍，否则不知道该在哪一边二分。
- **判定的是「边数最少」而不是「成本最小」**：money 已经把边的成本转化成了「用不用得上」的准入条件，剩下的问题里所有可用边地位平等 —— 所以用 **BFS 分层**，而不是带权最短路。
- **二分值域取 `[0, max_w]`**："最小可行 money" 必然落在这个闭区间内（`money = max_w` 等价于全图可用），用左闭右开的 `range(max_w + 1)` 配 `bisect_left` 找第一个 `True`。
- **无解 = 整个区间都是 False**：此时 `bisect_left` 返回 `max_w + 1`，用它来判断 -1。
- **BFS 可以在到达终点时提前返回**：第一次松弛到 n-1 的层数已经是理论最小值，不需要把队列跑完。

## 三、代码实现

### 最终代码

```python
# 截图里这三个 import 未出现（LeetCode 判题机已预置），此处补齐以便本地直接运行
from typing import List
from collections import deque
from bisect import bisect_left


class Solution:
    def minCost(self, n: int, edges: List[List[int]], k: int) -> int:
        if n == 1:                      # 按约束 2 <= n，此分支不会触发，属防御性写法
            return 0

        g = [[] for _ in range(n)]      # 邻接表：(邻居, 该边的修复成本)
        max_w = 0
        for u, v, w in edges:
            g[u].append((v, w))
            g[v].append((u, w))
            if w > max_w:
                max_w = w

        def check(money: int) -> bool:
            """预算为 money 时，能否用不超过 k 条边从 0 走到 n-1"""
            dist = [float('inf')] * n   # dist[x]：到达 x 的最少边数
            q = deque([0])
            dist[0] = 0
            while q:
                x = q.popleft()
                for y, w in g[x]:
                    if w <= money:                  # 这条边已被修好，可用
                        if dist[y] > dist[x] + 1:   # 找到了更少的边数，更新并入队
                            dist[y] = dist[x] + 1
                            if y == n - 1:
                                return dist[y] <= k
                            q.append(y)
            return dist[n - 1] <= k

        # 在 [0, max_w] 上二分最小的可行 money（range 左闭右开，故上界写 max_w + 1）
        ans = bisect_left(range(max_w + 1), True, key=check)
        return -1 if ans > max_w else ans
```

## 四、复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| :--- | :--- | :--- |
| **最终代码** | O((n + m) · log W) | O(n + m) |
| 朴素解法（枚举候选 money 值 + BFS） | O(m · (n + m)) | O(n + m) |
| 理论下界 | Ω(n + m) | O(n + m) |

> 复杂度中的 **n 指节点数，m 指边数**；**W = max(w_i) ≤ 10^9** 是边权上界，也就是二分值域的规模，log W ≈ 30。
>
> - **邻接表只建一次** O(n + m)，之后的每次判定都复用它。
> - **每次 `check` 是一次 BFS**，最坏情况遍历该预算下所有可用边，O(n + m)。
> - **二分共 O(log W) 轮**，故总共 O((n + m) · log W)。
> - 对比朴素解：把「枚举 O(m) 个候选」换成「二分 O(log W) 轮」，在 m = 10^5 时判定次数从 10^5 降到约 30。

## 五、优化评估

**结论**：时间复杂度已到本题可行解的下界量级，**没有渐近改进空间**，只剩「二分轮数 vs 预处理代价」与常数层面的取舍。

### 瓶颈分析

- 时间支配项是 `(n + m) · log W`：每轮判定都要重新分配 `dist` 数组（O(n)），并可能扫过该预算下所有可用边（O(n + m)）；而二分本身要跑 log W ≈ 30 轮。
- 空间上，邻接表 O(n + m) 是必须的（每条边都要在两个端点各存一份），判定用的 `dist` 是 O(n)，同阶，无法再降。

### 可优化空间

- **值域二分 ↔ 下标二分**：当前是在 `[0, max_w]` 上做值域二分，轮数约 `log W ≈ 30`，好处是**完全不必排序**，预处理保持 O(n + m)。另一种写法是先把所有边权排序去重、对其下标二分，轮数降到 `log m ≈ 17`，但要多付一次 O(m log m) 排序和 O(m) 去重空间。这是**轮数换预处理**的取舍，两种写法在本题规模下都能通过。
- **为什么不可能更好**：任何解都必须读完所有边才能知道图的结构（Ω(m)），也必须至少做一次图遍历才能判断 0 到 n-1 在当前可用子图下是否可达（Ω(n + m)）。二分是对「答案位置未知」所必须付出的代价。

### 常数级优化（可选）

- `dist` 数组在这里同时承担「层数记录」和「访问标记」两个职责。若不需要层数数值，可以换成一个 `visited` 布尔数组 + 队列按层处理（外层 `while` 内再套一层处理当前整层），省掉与 `float('inf')` 的比较；代价是代码多一层循环结构，可读性略降。
- BFS 队列用 `deque` 与用 `list` 配头指针在本写法下等价（只在一端取、在另一端加）；用 `deque` 更直观。

## 六、易错点与总结

### 易错点

- **二分方向搞反**：本题谓词是「money 越大越容易为 True」，要找的是**第一个 True**，所以用 `bisect_left`。把单调方向想反就会得到完全错误的结果。
- **误用带权最短路**：`w` 只是「修不修得起」的门槛，不是路径要累加的长度。一旦 `w <= money`，这些边之间没有任何权重差异，用 Dijkstra 反而把问题做复杂、口径也跑偏了。
- **无解分支漏判**：整段区间都为 False 时，`bisect_left` 返回的是上界 `max_w + 1`，必须显式判断并返回 -1，不能直接把它当答案返回。
- **`bisect_left` 的 `key` 参数需要 Python 3.10+**：低版本没有 `key`，只能手写二分，或退化成先物化布尔数组再二分（空间 O(W)，`W` 可达 10^9，不可取）。
- **提前返回时别忘了比 k**：走到 n-1 只说明"能到"，返回的必须是 `dist[y] <= k` 而不是 `True`。
- **money 可以取 0**：本题 `w_i >= 1`，`money = 0` 时没有任何边可用，所以只要 `n >= 2` 该处必定为 False —— 这也保证了下界取 0 是安全的。`n == 1` 的守卫在给定约束（`2 <= n`）下不会触发，保留无害。

### 题型套路沉淀

- **「最小可行阈值 / 最小化最大值」型 → 二分答案**：只要谓词关于某个参数单调，就可以把「枚举参数」降成「二分参数」，这是二分答案的统一入口。
- **二分答案的固定三步**：① 用业务语言写清谓词 `check(x)` 到底在判定什么；② 验证单调性（此处：`money ↑` ⇒ 可用边集合 ⊇ ⇒ 最少边数 ≤）；③ 确定二分边界与无解判据（`[0, max_w]`，越界即 -1）。
- **无权最短路边数 = BFS 分层**：一旦问题被归约成「经过的边数最少」，就别再想带权最短路。
- **二分 + BFS 是图论里的高频组合**：凡是「阈值越小越做不到、越大越能做到」且判定需要跑一遍图的问题，基本都是「二分阈值 + 对可行子图做 BFS」这一套。
