# 3143. 正方形中的最多点数

> **难度**：中等
> **标签**：数组 · 哈希表 · 字符串 · 二分查找
> **原题链接**：https://leetcode.cn/problems/maximum-points-inside-the-square/

---

## 一、题目描述

给定 `n` 个坐标互不相同的点 `points[i] = (x_i, y_i)` 及各自的标签 `s[i]`。要求选一个**中心在原点、四条边平行于坐标轴**的正方形，使得落在正方形内（含边界）的点中**不存在两个标签相同的点**——这样的正方形称为「合法」。

求合法正方形最多能包含多少个点。边长可以为零。

关键是把「正方形」换成**单个标量**：设正方形的**半边长**为 `t`（边长即 `2t`），则点 `i` 在正方形内 ⟺ `|x_i| ≤ t` 且 `|y_i| ≤ t` ⟺ `max(|x_i|, |y_i|) ≤ t`。记 `r_i = max(|x_i|, |y_i|)` 为「点 `i` 所需的最小半边长」，于是**半边长 `t` 的正方形恰好包含所有 `r_i ≤ t` 的点**。

### 示例

```text
示例 1
输入：points = [[2,2],[-1,-2],[-4,4],[-3,1],[3,-3]], s = "abdca"
输出：2
解释：半边长 t = 2（边长 4）时圈住 points[0]（标签 a）与 points[1]（标签 b），标签互不相同；
      再放大到 t = 3 就会同时圈进 points[0] 与 points[4]——两者标签都是 a，立刻不再合法。

示例 2
输入：points = [[1,1],[-2,-2],[-2,2]], s = "abb"
输出：1
解释：t = 1 时只有 points[0]（标签 a）进圈，合法；t = 2 时两个标签为 b 的点一起进圈，非法。

示例 3
输入：points = [[1,1],[-1,-1],[2,-2]], s = "ccd"
输出：0
解释：points[0]、points[1] 标签相同且半径都是 1，想圈住任一个就必然圈住另一个；
      任何合法正方形都只能取 t = 0（圈不到点），故答案为 0。
```

### 约束条件

- `1 <= s.length, points.length <= 10^5`
- `points[i].length == 2`
- `-10^9 <= points[i][0], points[i][1] <= 10^9`
- `s.length == points.length`
- `points` 中的点坐标互不相同
- `s` 只包含小写英文字母

## 二、解题思路

### 核心思想

**把正方形参数化成半边长 `t` 后，「合法性」和「点数」都随 `t` 单调变化 —— 于是答案就是「最大的那个合法 `t` 圈住的点数」，二分即可。**

### 思路演进

1. **暴力解法**：只有 `n` 个不同的 `r_i` 值值得作为候选半边长（两个相邻候选之间，圈住的点集完全不变）。对每个候选 `t` 扫一遍全部点、用哈希表统计标签是否重复：判定 O(n) × 候选 O(n) = **O(n²)**，`n = 10^5` 时约 10^10 次操作，必然超时。

2. **观察到单调性**：`t` 变大时，圈住的点集**只增不减**。由此立刻得到两条性质：
   - 集合变大只会**新增**冲突、不会消解冲突 ⇒ **`legal(t)` 关于 `t` 单调递减**（`t` 合法则更小的 `t` 也合法）；
   - 圈住的点数关于 `t` 单调不减 ⇒ **在所有合法 `t` 里，最大的那个必然拿到最多点数**。
   一条提供判定依据、一条保证目标可取到，两者合起来说明：**只需要找到最大的合法 `t`**。

3. **优化为二分答案**：`t` 的候选范围是整数 `[0, R]`（`R = max r_i`）。二分判定函数 `check(t)`：扫描所有点，把 `r_i ≤ t` 的点的标签计数，一旦某标签出现**第二次**就立即返回 `False`。二分求「最后一个 `check` 为真的整数 `t`」。

4. **收尾统计**：二分得到的是**半边长**而不是点数，必须再扫一遍统计 `r_i ≤ left` 的个数。（当然也可以把上一步的判定改成返回个数，但那样每轮判定就不能提前返回了。）

> 二分区间的两端都是哨兵：左端 `-1` 对应「空正方形」，必然合法；右端 `R + 1` 只用来保证不小于任何候选 `t`。

### 关键点

- **把二维几何条件降成一维阈值**：正方形内 ⟺ `max(|x|, |y|) ≤ t`。这一步之后，「正方形」这个几何对象就消失了，剩下的只是一个阈值问题。
- **两个单调性缺一不可**：只有「点数单调」没法二分（没有可判定的谓词）；只有「合法性单调」也不够（合法集里最大的 `t` 未必点数最多，虽然本题恰好也满足）。写二分前这两条要分别验证。
- **判定只关心「有没有重复」，不关心重复了几次**：所以一旦计数超过 1 就可以立刻返回。
- **二分得到的是阈值，不是答案**：`left` 只是最大合法半边长，点数必须单独统计。
- `t = 0` 一定合法：边长 0 的正方形只含原点，而坐标互不相同 ⇒ 至多圈到一个点，不会有标签冲突。

## 三、代码实现

### 最终代码

```python
from typing import List
from collections import defaultdict


class Solution:
    def maxPointsInsideSquare(self, points: List[List[int]], s: str) -> int:
        # 最大的 |坐标|：半边长超过它就没有意义（所有点都已进圈）
        lenmax = max((num for row in points for num in row), key=lambda x: abs(x))
        left = -1                       # 下哨兵：半边长 -1 ⇒ 空正方形，一定合法
        right = abs(lenmax) + 1         # 上哨兵：取到比所有候选半边长都大
        n = len(points)

        def check(t: int) -> bool:
            """半边长 t 的正方形（边长 2t）是否合法：圈内没有标签相同的两个点"""
            cnt = defaultdict(int)
            for i in range(n):
                if abs(points[i][0]) <= t and abs(points[i][1]) <= t:
                    cnt[s[i]] += 1
                    if cnt[s[i]] > 1:
                        return False
            return True

        while left + 1 < right:         # 求「最大的合法半边长」
            mid = (left + right) // 2
            if check(mid):
                left = mid
            else:
                right = mid

        ans = 0
        for i in range(n):              # 半径 ≤ left 的点就是最多能圈住的点
            if abs(points[i][0]) <= left and abs(points[i][1]) <= left:
                ans += 1
        return ans
```

> 截图里没有 `List`、`defaultdict` 的 import，已补上；其余与提交版本一致。

## 四、复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| :--- | :--- | :--- |
| **最终代码（二分答案）** | O(n log M) | O(1) |
| 朴素解法（枚举每个候选 t 各扫一遍） | O(n²) | O(1) |
| 计数优化版（见第五节，直接定位冲突阈值） | O(n) | O(n) |
| 理论下界 | O(n) | O(1) |

> 复杂度中的 `n` 指点数（`points` 的长度）；`M = max(|x_i|, |y_i|) ≤ 10^9`，二分次数为 `⌈log₂(M + 2)⌉ ≈ 30`。

- **时间**：二分约 30 轮，每轮 `check` 扫描 `n` 个点，最后再扫一遍统计 ⇒ `O(n log M)`。`n = 10^5` 时为「30 × n」量级，相比朴素的 `n²` 少了一个数量级还多。
- **空间**：判定只用一张「标签 → 出现次数」的表；标签取值范围只有 26 个小写字母 ⇒ `O(1)`。（若不假设字母表大小固定，则为 `O(min(n, |Σ|))`。）

## 五、优化评估

**结论**：时间**仍有优化空间** —— 本题的判定结构允许把二分整个省掉。

### 瓶颈分析

`check(t)` 每次都要从零重扫全部 `n` 个点来判断「哪些点进圈」，而二分要跑约 30 轮 ⇒ 时间堆在 `O(n log M)`。但二分本来就是「候选太多、只能逐个试」时的妥协手段；本题的「最大合法 `t`」其实可以**直接算出来**。

### 可优化空间

对一个固定标签 `c`，把它名下的点按半径升序排成 `r_c⁽¹⁾ ≤ r_c⁽²⁾ ≤ …`。显然：

- 只要 `t < r_c⁽²⁾`，标签 `c` 最多只有一个点进圈；
- 一旦 `t ≥ r_c⁽²⁾`，`r_c⁽¹⁾` 和 `r_c⁽²⁾` 对应的两个点会**同时进圈**，立刻冲突。

也就是说，「标签 `c` 造成的冲突最早出现在半边长 `r_c⁽²⁾`」。对所有出现过至少两次的标签取最小：

```text
limit = min over 出现过 ≥2 次的标签 c ( r_c⁽²⁾ )
```

`limit` 就是**整个问题中最早发生冲突的半边长**：所有 `t < limit` 都合法，所有 `t ≥ limit` 都非法。于是答案 = 半径 `r_i < limit` 的点数；若没有任何标签出现两次，则 `limit = +∞`，答案是 `n`。

只需求出每个标签的**两条最小半径**，一次遍历即可完成 —— 判定与二分一起消失。

### 优化代码

```python
from typing import List


class Solution:
    def maxPointsInsideSquare(self, points: List[List[int]], s: str) -> int:
        INF = float("inf")
        r = [max(abs(x), abs(y)) for x, y in points]   # 每个点所需的最小半边长

        best1 = {}      # 标签 -> 该标签的最小半径
        best2 = {}      # 标签 -> 该标签的次小半径
        for v, ch in zip(r, s):
            if v < best1.get(ch, INF):        # 刷新最小值，旧的最小值退位为次小
                best2[ch] = best1.get(ch, INF)
                best1[ch] = v
            elif v < best2.get(ch, INF):      # 落在「最小」与「次小」之间
                best2[ch] = v

        # 最早冲突的半边长 = 所有重复标签的次小半径的最小值
        limit = min(best2.values(), default=INF)
        return sum(1 for v in r if v < limit)
```

**优化理由**：二分是「判定便宜但候选无法直接定位」时的手段；一旦发现答案是「某个结构化事件最早发生的阈值」，就可以把事件阈值直接算出来。本题冲突事件的阈值恰好只依赖每个标签最小的两条半径，因此 `O(n log M)` → `O(n)`。代价是多存一个长度 `n` 的半径数组，空间从 `O(1)` 升到 `O(n)`。

### 常数级优化（可选）

- `check` 只判断「有没有重复」，用 `set` 记录已出现的标签即可（`if s[i] in seen: return False`），不必维护计数；语义完全等价，还省掉一次读改写。
- `max((num for row in points for num in row), key=lambda x: abs(x))` 求的是「绝对值最大的那个坐标」，等价于更直白的 `max(abs(v) for row in points for v in row)`，少一层 `key` 回调。

## 六、易错点与总结

### 易错点

- **把 `t` 当成边长**。本题参数是**半边长**：边长 `2t` 的正方形圈住的是 `max(|x|, |y|) ≤ t` 的点。`points[0] = (2,2)` 恰在边长 4（`t = 2`）的边界上，而题目规定边界算内部 —— 用 `<` 判定就会漏掉这一点。
- **二分方向写反**。合法的是 `t` 的**小端**，要的是「最大的合法 `t`」⇒ `check(mid)` 为真时收 `left`、为假时收 `right`。反过来写会直接得到 `-1` / `0`。
- **二分完直接返回 `left`**。`left` 是半边长不是点数，必须再统计一遍 `r_i ≤ left` 的个数。
- **上哨兵必须严格大于 `max r_i`**。若取 `right = R`：当所有点标签互不相同时 `check` 全程为真，`left` 会停在 `R - 1`，把半径恰好为 `R` 的那批点全部漏掉。取 `R + 1` 才安全。
- **计数的比较方向**：是 `cnt[s[i]] > 1` 就返回 `False`（出现第二个同标签点即非法）。写成 `>= 1` 会让判定恒为假。

### 题型套路沉淀

- **「中心固定、大小可变的正方形／圆／菱形」→ 立刻参数化成单个标量阈值**。轴平行正方形用 `r = max(|x|, |y|)`，圆形用 `√(x² + y²)`，之后几何形状就退化成「半径 ≤ t」的一维条件。
- **二分答案的两个前提，写之前分别验证**：① **判定单调**（本题：合法 ⇒ 更小也合法）；② **目标单调**（本题：点集随 `t` 只增不减 ⇒ 最大合法 `t` 就是最优解）。缺任何一条，二分都会给出错误结果。
- **「最早的冲突阈值」常常可以直接算，不必二分**。当判定形如「出现重复 / 越过边界 / 不满足某结构条件」时，答案往往等价于「最早出事的那一刻」，而那一刻通常只依赖极少量信息（本题：每个标签的两条最小半径）。**先想能不能直接定位，再退到二分。**
- **哨兵值的选择是承重的**：下哨兵要落在「谓词确实为假（或跳过）」的一侧、上哨兵要落在「一定不小于所有候选」的一侧，否则全真 / 全假两种退化情形会各自出错。
