# 1802. 有界数组中指定下标处的最大值

> **难度**：中等
> **标签**：二分 · 贪心 · 数学
> **原题链接**：https://leetcode.cn/problems/maximum-value-at-a-given-index-in-a-bounded-array/

---

## 一、题目描述

给定三个正整数 `n`、`index`、`maxSum`，构造一个长度为 `n` 的**正整数**数组 `nums`，要求：

- 相邻元素之差的绝对值不超过 1，即 `|nums[i] - nums[i+1]| <= 1`；
- 整个数组的元素之和不超过 `maxSum`。

在所有满足条件的数组中，让 `nums[index]` 尽可能大，返回这个最大值。

### 示例

```text
输入：n = 4, index = 2, maxSum = 6
输出：2
解释：[1,1,2,1] 与 [1,2,2,1] 都满足条件；不存在让 nums[2] 更大的合法数组。

输入：n = 6, index = 1, maxSum = 10
输出：3
```

### 约束条件

- `1 <= n <= maxSum <= 10^9`
- `0 <= index < n`

---

## 二、解题思路

### 核心思想

**把「求最大值」换成「判断某个值能不能取到」，再利用可行性的单调性做二分答案。** 判断 `nums[index] = a` 是否可行，只需算出「在 `nums[index] = a` 的前提下数组能达到的最小总和」，与 `maxSum` 比大小。

### 思路演进

1. **暴力解法**：从小到大枚举 `a`，对每个 `a` 真的构造一个 `nums[index] = a` 的合法数组并累加验证。`a` 的上界是 `maxSum`（可达 `10^9`），每次构造又是 O(n)，整体 O(maxSum · n)，必然超时。

2. **观察到「只需要算最小总和」**：判定 `a` 可行要的是**存在性** —— 只要存在一个合法数组其总和不超过 `maxSum`，`a` 就可行。而"总和最小"这件事有确定答案：取 `nums[index] = a`，从 `index` 向两侧每走一步把值减 1，减到 1 之后就一直是 1。

   为什么这就是最小？对任意 `k`，由相邻差不超过 1 反复套用得 `nums[index ± k] >= a - k`；再加上每项必须是正整数，于是 `nums[index ± k] >= max(a - k, 1)`。而这些下界**可以同时取到** —— 逐项取这个值得到的数组相邻差恰好是 0 或 1，本身合法。所以逐项取到这些下界的数组，就是"给定 `nums[index] = a` 时总和最小的数组"。

   ⇒ 判定化简成一句话：`min_sum(a) <= maxSum`。

3. **观察到「单调性」**：`a` 越大，逐项下界 `max(a - k, 1)` 逐项不减，所以 `min_sum(a)` 关于 `a` 单调不减；判定谓词因此形如「可行、可行、…、可行、不可行、…」。**二分答案成立**，把枚举 `a` 换成对 `a` 二分，每轮只需算出 `min_sum`。

4. **把 `min_sum` 压成 O(1)**：一侧的最小总和是「一段等差数列 + 尾巴全是 1」的分段式子，按"这一侧的位置够不够减到 1"分类讨论，用等差数列求和公式直接算，不必真的填数组。

### 关键点

- **两个端点**：`a = 1` 一定可行（全 1 数组总和为 `n <= maxSum`）；`a = maxSum + 1` 一定不可行（光 `nums[index]` 这一项就超过 `maxSum`，还要再叠上 `n - 1` 个至少为 1 的元素）。这就是二分的初始 `left` / `right`。
- **单侧最小和的两种形态**：记 `size = a - 1`（峰值相对"底 1"的高度，也就是最多能向外递减几步），某一侧有 `len` 个位置：
  - `len <= size`：这一侧最远的那个位置是 `a - len >= 1`，还没触底（`len == size` 时恰好等于 1），该侧总和为 `a-1, a-2, …, a-len` 的等差数列；
  - `len > size`：递减到 1 之后，剩下 `len - size` 个位置只能全填 1。
- **常数剥离**：先把 `maxSum` 减掉 `n`（把"全 1 的底"扣掉），后面只讨论"高出 1 的那部分"，公式短很多 —— 代码里的 `mx_sum = maxSum - n` 就是这个意思。
- **代码里的 `l_s` / `r_s`**：`size = mid - 1` 是"梯级总数"；`l_s = max(size - index, 0)` 是左侧"梯级没用完的**余量**"（左侧只有 `index` 个位置，消耗不掉这么多梯级）；右侧位置数为 `n - 1 - index`，同理 `r_s = max(size - (n-1-index), 0) = max(index + size - n + 1, 0)`。
  把上面两种形态的求和式合并化简后，"高出 1 的部分"总量恰好是：

  ```text
  extra(a) = size^2 - l_s*(l_s-1)/2 - r_s*(r_s-1)/2
  ```

  两个 `l_s*(l_s-1)/2`、`r_s*(r_s-1)/2` 就是"没触底"时要把虚高的梯级扣掉的部分；某一侧触底时对应的 `l_s`（或 `r_s`）为 0，该项自动消失，**不需要额外特判**。于是判定条件是：

  ```text
  size^2 - l_s*(l_s-1)/2 - r_s*(r_s-1)/2 <= maxSum - n
  ```

  代码为了复用 `mid`，把 `size^2 = (mid-1)^2` 展开成 `mid*(mid-1) - mid + 1`，所以看到的是那串 `mid * (mid - 1) - … - mid + 1`。
- **左闭右开的相邻式二分**：`left` 恒为"已知可行"、`right` 恒为"已知不可行"，循环条件 `while left + 1 < right`，结束时 `left` 就是最大的可行值。

## 三、代码实现

### 最终代码

```python
class Solution:
    def maxValue(self, n: int, index: int, maxSum: int) -> int:
        left = 0
        right = maxSum + 1                # 不可行的哨兵上界
        mx_sum = maxSum - n               # 扣掉“全 1 的底”，之后只讨论高出 1 的部分
        while left + 1 < right:
            mid = (left + right) // 2     # 候选的 nums[index] 取值
            size = mid - 1                # 峰值相对底 1 的高度 = 可向外递减的步数
            l_s = max(size - index, 0)            # 左侧“梯级没用完”的余量
            r_s = max(index + size - n + 1, 0)    # 右侧“梯级没用完”的余量
            if mid * (mid - 1) - l_s * (l_s - 1) // 2 - r_s * (r_s - 1) // 2 - mid + 1 <= mx_sum:
                left = mid                # mid 可行
            else:
                right = mid               # mid 不可行
        return left
```

## 四、复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
| :--- | :--- | :--- |
| **最终代码** | O(log maxSum) | O(1) |

| 理论下界 | O(1) | O(1) |

## 五、优化评估

**结论**：在"二分答案"这条路上，时间 O(log maxSum) 与空间 O(1) 都已到位，能再聊的只有"能不能不二分"。

### 瓶颈分析

时间全部花在约 30 轮二分上，每轮是一次纯算术的 O(1) 判定，内部没有可压缩的循环；空间上只用几个整数变量，无法再降。

### 可优化空间

理论上可以**直接解方程**做到 O(1)：`min_sum(a)` 是关于 `a` 的**分段二次函数**，分段点由 `a - 1` 与两侧位置数的大小关系决定（最多三段）。在每一段内它是开口向上的二次函数，求 `min_sum(a) <= maxSum` 的最大整数解，只需解一元二次不等式并对判别式开方取整。

但这样要写三段分支、还要处理开方取整的 ±1 边界，出错概率明显高于二分；而本题 `maxSum <= 10^9`，二分的约 30 轮成本可以忽略。**在这里用二分换代码可靠性，是更划算的选择。**

### 优化代码

下面是等价但更易读的写法：把"最小总和"按定义拆开，可以直接对照上面的推导逐项核对，不必先信任那串合并后的算术表达式。

```python
class Solution:
    def maxValue(self, n: int, index: int, maxSum: int) -> int:
        def side_extra(length: int, size: int) -> int:
            """一侧在“峰值高出底 1 共 size 层”时，该侧所有位置高出的总量。
            length 为该侧位置数（左侧 index 个，右侧 n-1-index 个）。"""
            m = min(length, size)                    # 真正还能保持 > 1 的位置数
            return m * size - m * (m + 1) // 2       # (size-1) + (size-2) + ... + (size-m)

        def min_sum(a: int) -> int:
            size = a - 1
            # a 本身 + 其余 n-1 个位置各自至少为 1 + 两侧高出 1 的总量
            return a + (n - 1) + side_extra(index, size) + side_extra(n - 1 - index, size)

        lo, hi = 1, maxSum + 1                       # lo 可行，hi 不可行
        while lo + 1 < hi:
            mid = (lo + hi) // 2
            if min_sum(mid) <= maxSum:
                lo = mid
            else:
                hi = mid
        return lo
```

**优化理由**：`side_extra` 直接实现"这一侧有多少个位置能高于 1、各自高出多少"的等差数列求和，把原代码里合并后的常数式子还原成有语义的两步，便于复核；复杂度与最终代码相同。

### 常数级优化（可选）

- 二分上界可从 `maxSum + 1` 收紧到 `maxSum - n + 2`（因为 `nums[index] <= maxSum - (n - 1)`），只少一两轮，收益极小。
- 判定式里的 `mid * (mid - 1)`、`l_s * (l_s - 1)` 等不存在重复计算；把 `mid - 1` 先存进 `size` 再复用，代码已经这么做了。
- 若改用 C++ / Java 实现，`n`、`maxSum` 可达 `10^9`，`size^2` 约 `10^18`，中间量**必须用 64 位整型**，否则溢出后判定会给出莫名其妙的答案。Python 整数无此问题。

## 六、易错点与总结

### 易错点

- **忘记"触底"**：数组里不允许出现 0，从峰值往外最多递减 `a - 1` 步，更远的位置只能是 1。若一路按 `a - k` 往下算，会低估最小总和，从而返回偏大的答案。
- **`size` 取成 `a`**：底是 1 不是 0，可递减的步数是 `a - 1`。
- **二分端点写错**：`left` 必须从"一定可行"处起步，`right` 从"一定不可行"处起步（本题取 `maxSum + 1`）。用 `while left + 1 < right` 的相邻式写法，`mid` 永远落在开区间内部（因此 `left` 取 0 这个哨兵也不会被判定到），不会死循环，退出后直接返回 `left`。
- **`l_s` / `r_s` 方向搞反**：它们表示"梯级没用完的**余量**"，`size` 越大、该侧位置数越少，余量越大，是要从总量里**扣掉**的部分（触底时余量为 0）。写反了在小数据上可能侥幸通过，`n` 与 `index` 差距大的用例会挂。
- **非 Python 语言的整数溢出**：见上节。

### 题型套路沉淀

- **二分答案的固定骨架**：① 把"求最优值"改写成"判定候选值 x 是否可行"；② 证明可行性对 x 单调（本题靠 `min_sum(a)` 单调不减）；③ 定出"一定可行"与"一定不可行"两个端点；④ 用左闭右开的相邻式二分，返回最后一个可行点。
- **判定函数的一条常用手段：极值构造 + 公式求和** —— 把"是否存在合法方案"转化为"最优（本题是总和最小）方案是否满足限制"，再用等差数列这类闭式公式 O(1) 算出来。
- **写判定函数的方法**：先按"分情况 + 逐项累加"写出直观版本，确认无误后再用代数恒等式合并成无分支的紧凑表达式；同时要能**反向读懂**合并后的式子（本题的 `- mid + 1` 就是 `size^2` 展开留下的痕迹）。
- 见到「构造数组 + 最大化某个位置的值 + 相邻差受限」这类描述，先想"以目标位置为山峰、向两侧线性下降"的极值构造。
